# Documentation search review

Open `index.html` in this directory through a static web server, search for a setting or topic, expand the contents, and try “Show in contents.” Feedback on finding material is welcome.

This optional review page retains selected authored excerpts and canonical documentation destinations. It is not the published documentation or a software/scientific validation. Clinical instructions remain outside the search pilot. Source data is a retained capture; source freshness varies outside the specifically verified targets.

No build, credentials, backend or installation is needed to host these static files. Paths are relative for root and project-subpath hosting. Existing published documentation links intentionally open the official website. Enabling hosting or changing Pages/domain settings is a separate owner decision.
